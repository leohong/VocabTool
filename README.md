## 📱 產品簡介 (Overview)

**極限單字特訓系統 Mobile App** 專為高強度的長期單字記憶計畫（如征服國中 2,000 單字、高中 7,000 單字）而設計，核心特色包括：

* ⚡ **雙階段流水線訓練**：第一關快速閃卡篩選 ➔ 第二關測驗（預設為強制盲測全拼寫 / 可切換四選一）。
* 🔘 **全域特訓模式切換**：支援全域切換 `🎴 閃卡模式` 與 `🔘 4選1選擇題模式`。
* 🔥 **動態錯題懲罰**：雙倍消除演算法（拼錯越多次需要連續拼對越多次才能畢業）。
* 🏛️ **間隔重複與幽靈突襲**：4 階段間隔複習（7天 ➔ 21天 ➔ 60天 ➔ 180天 ➔ 永久免疫）。
* 🎧 **盲聽特訓播放器**：美式發音與台灣國語，支援自訂語速、字母拼讀停頓、聽寫高亮動畫與遮蔽模式。
* 💾 **100% 離線可用與極速備份**：資料本機持久化儲存，支援手動 JSON 全系統備份與 TXT 匯出入，100% 離線可用。

## 🎮 主介面與操作指南 (User Guide)

### 1. 指揮中心按鈕功能
* **⚡ 發動今日特訓**：開始當天設定的新單字特訓（第一關為閃卡篩選，第二關依模式進行全拼寫或四選一）。特訓中會自動安插今日到期的歷史「幽靈單字 👻」進行突襲。
* **🔥 降溫：錯題大會考**：從當前錯題集中隨機抽取最多 50 個字進行特訓：
  - 在 `🎴 閃卡模式` 下：直接進行「純拼寫盲測」。
  - 在 `🔘 4選1模式` 下：變為「四選一選擇題測驗」（答錯視同拼錯重寫並累計錯題）。
* **🏛️ 深度：歷史隨機抽查**：隨機抽取最多 50 個已封存於歷史殿堂的單字進行檢測：
  - 在 `🎴 閃卡模式` 下：直接進行「純拼寫盲測」。
  - 在 `🔘 4選1模式` 下：變為「四選一選擇題測驗」（答錯視同拼錯，退回錯題集）。
* **🎧 聽讀：聽音背單字**：進入聽音背單字播放器。支援自訂單字範圍、字母拼讀、中文釋義與例句朗讀。

### 2. 特訓模式開關說明 (⚡ 特訓模式)
位於儀表板「📢 自動發音」下方，提供全域膠囊二選一切換：
* **`🎴 閃卡`（預設）**：
  - 今日特訓：第一關閃卡瀏覽 ➔ 第二關強制盲測全拼寫。
  - 錯題大會考 / 歷史隨機抽查：直接進行純拼字測驗。
* **`🔘 4選1`**：
  - 今日特訓：第一關閃卡瀏覽 ➔ 第二關變為 4 選 1 中文選擇題測驗。
  - 錯題大會考 / 歷史隨機抽查：變為 4 選 1 中文選擇題測驗（4選1模式下例句自動遮蔽中文翻譯）。
